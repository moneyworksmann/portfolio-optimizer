⚡ QUICK START (3 STEPS):

STEP 1: Install Required Libraries
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

In Terminal/Command Prompt, run:

  python3 portfolio_optimizer.py

✅ Wait 1-2 minutes while it:
   - Fetches real-time prices from Yahoo Finance
   - Calculates optimal portfolio allocation
   - Generates 5 professional charts
   - Updates Investment_Portfolio_Tracker.xlsx

✅ Now open Investment_Portfolio_Tracker.xlsx
   - Go to "Optimization" tab

❓ COMMON ISSUES & FIXES:

Issue: "Command not found: python3"
Fix:   Try "python" instead of "python3"
       Or install Python from python.org

Issue: "ModuleNotFoundError: yfinance"
Fix:   Run: pip install yfinance
       (Sometimes you need: pip3 install yfinance)

Issue: Charts don't show up
Fix:   Close Excel
       Re-run: python3 portfolio_optimizer.py
       Reopen Excel

Issue: "Permission denied"
Fix:   Mac: chmod +x portfolio_optimizer.py
       Then: python3 portfolio_optimizer.py

Issue: "No module named matplotlib"
Fix:   pip install matplotlib
